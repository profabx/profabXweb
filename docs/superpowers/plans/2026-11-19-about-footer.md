# 关于页页脚排版修正

问题：版权/公司/联系链接放在 about-content.json 正文内部，且底部另外渲染 PageFooter。旧块没有布局规则，邮箱被独立挤到下一行，字号和链接样式也受正文规则影响。

参照 Xometry 与 Wenext 的版权与联系信息分层，将旧块移除，About 专用 PageFooter 统一管理底部信息。保留白底蓝色布局与无重复 Logo；上行为服务说明与报价入口，下行为版权、公司主体及官网/邮箱。桌面底行左右对齐，平板与手机分行，联系链接默认使用辅助文字颜色，悬停/键盘聚焦有反馈。其他页面页脚不变。

案例：https://xometry.asia/zh-hans/ 、 https://www.wenext.com/ 。已查看网页底部实际截图。

验证：公开/管理版各测试 1440、1024、768、390、320 宽度，检查仅一套页脚、版权年份、联系链接、左右/分行布局、键盘聚焦与无横向溢出；保存桌面/手机截图并检查；两版构建通过。Browser plugin not available，采用无界面 Playwright 验证，不自动打开用户预览窗口。
