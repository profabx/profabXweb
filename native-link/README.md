# ProFabX Live 原生联动版

适配 Bambu Studio `v02.08.02.61`，提交 `926a7192574bcb9b3a732e1ec59a46d79cb45466`。独立应用键名为 `ProFabXLive`，原有 `C:/Bambu Studio` 安装不会被修改。

React 与原生适配器通过本机HTTP交换内存中的变换，约每100ms一次，不保存/重载3MF。选用 Bambu 已有异步HTTP库以减少编译和线程依赖；这不是文件轮询。初次连接仍需要生成一次带稳定对象ID的3MF工程，用来建立源几何基准。

## 编译

在独立目录获取官方源码并切换到上述标签。需要上游支持的 MSVC、Windows10/11 SDK、CMake、Git和Perl。使用管理员权限安装工具不是脚本的工作；可在配置好的开发者命令行运行。

```powershell
git clone --depth 1 --branch v02.08.02.61 https://github.com/bambulab/BambuStudio.git BambuStudio-ProFabX
node native-link/build.cjs --source C:/short/BambuStudio-ProFabX --sdk "C:/Program Files (x86)/Windows Kits/10/Include/10.0.22621.0"
```

`--generator Ninja` 支持已配置好MSVC环境的便携构建；`--prefix` 可指定已编译的Bambu依赖前缀，`--pkg-config` 可指定 pkgconf 可执行文件。构建后会补齐依赖 DLL。Windows资源编译器对长命令行有限制，建议使用短源码路径。脚本固定校验源码提交，复制适配器，修改入口与应用键，构建依赖和程序。安装目标固定为与网页目录并列的 `ProFabXLink/runtime/`，编译成功后才写入SHA256构建清单。网页服务会校验清单、版本和适配器标记。构建产物默认 `integrationVerified:false`，在实际原生交互、断线与独立运行验证通过并记录之前，不会启用生产连接入口；模拟原生端测试不满足此条件。

源码变动包括 `adapter/` 中的C++文件、原生 `Plater.hpp/.cpp` 的启动入口、原生GUI源列表及 `version.inc`。`apply-adapter.cjs` 保留可重复应用的修改流程；不会调用已安装的原版程序注入代码。

## 使用与范围

网页“支撑与切片 → 实时双向联动 → 连接联动版”创建会话并打开独立程序。只有原生端完成对象身份、实例数和初始世界包围盒校验并发送心跳后，界面才显示“原生软件已连接”。

支持单个平台、每种零件一个独立对象/实例的刚性移动和旋转。原生对象模式和单体积部件模式的变换统一换算为世界增量；网页以同一初始几何计算离平台高度。新增/删除对象、网格编辑、缩放和多平台尚不属于实时协议。源模型和原始坐标保持不变。

会话使用分离的网页/原生随机凭据、递增序号、对象版本和操作锁。原生线程仅执行网络请求，所有模型和场景访问在GUI线程完成。

**最高优先级：不影响切片软件独立使用。** 原版安装、配置和工程不参与修改；独立版直接启动且没有联动描述文件时不会建立连接。网页启动会话使用私有数据目录，并禁止把新工程转发给已打开的切片软件窗口。发生同零件并发编辑、网络请求失败、网页离线或对象身份变化时，原生端停止联动并保留当前项目、摆放和未保存修改；不自动关闭、保存或重载工程。继续联动必须明确重新连接。普通移动、旋转、摆放和切片继续由原生软件处理。完整原生程序现已构建，实际GUI交互保护仍待验证。Windows 文件关联使用独立的 ProFabX.Live.1 标识，窗口标题包含 ProFabX Live。

摆放变动会使旧切片失效；支撑在重新切片后更新，不会随着拖动伪造支撑。现有“保存3MF后回传”功能保留，实时会话期间暂停旧文件监听。

## 验证说明

`tests/live-link*.test.js` 覆盖协议、鉴权、身份、坐标、并发和存活检查。`native-link/tests/` 是实际MSVC编译执行的C++状态与坐标测试。浏览器协议测试使用明确标注的模拟原生端，不能作为完整Bambu GUI联动成功的证据；完整程序已成功编译。实际独立 CLI 切片已生成真实 G-code，测试前后原版 EXE/DLL 哈希一致。自动启动曾出现 WebView2 异常；改由用户在资源管理器启动测试版后，实际 GUI 已完成模型绑定及双向移动验证。修正了网页导出工程的 Application 版本标识、耗材颜色与变体索引，避免原生导入重新居中或拒绝配置。真实网页与原生端移动交换期间 3MF 未改写，断开后原生进程和工程保留。随后真实 GUI 的 Z 轴旋转也已双向传递：网页发送 30°，原生拖动时网页收到 32.652°。该测试捕获首个变化后自动断开，未检查鼠标松开后的最终角度。真实连接已持续约 60 秒，覆盖一次约 7 秒 GUI 心跳停顿。心跳容限为 15 秒；显式断开立即失效。99 项 Node 测试及模拟端浏览器回归通过。本轮已完成真实GUI松手最终姿态、网页反向最终姿态、断开后独立保存与重开检查。当前构建 integrationVerified=true，正式入口开放，范围与数值见 VALIDATION.md。
